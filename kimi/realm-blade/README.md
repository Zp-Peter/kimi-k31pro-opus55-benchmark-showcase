# 界刃 / REALM BLADE

一款可完整试玩的 **3D 第一人称三渲二近战竞技 Demo**。四支双人队伍先分别营造四块区域，再随机交换出生区；真人玩家与一名 AI 队友对抗其余三支 AI 队伍。

## 启动

需要 Node.js 20.19+ 或 22.12+（Vite 7 要求）。

```bash
npm install
npm run dev
```

打开终端显示的本地地址（通常为 `http://localhost:5173`）。生产构建：

```bash
npm run build
npm run preview
```

使用桌面 Chrome / Edge / Firefox 和键鼠试玩。首次点击“入场”后浏览器会锁定鼠标；若准备倒计时结束时鼠标未锁定，会出现明确的“点击拔刀开战”按钮，此时 AI 与回合计时保持等待。中场重建若未恢复鼠标控制，也会显示“点击返回营造”，并在点击前暂停营造计时。

## 完整流程

1. 选择快速或长局模式，可直接修改目标分数。
2. 四队随机获得 A/B/C/D 中一块营造区。跟随世界标记与地图，第一人称进入本队区域。
3. 使用与金钱独立的 100 点预算放置、旋转、删除掩体；其他三队使用随机合法模板营造。
4. 锁定布局后显示换区图。每回合都以营造归属为基准做无固定点的随机排列：一一分配且绝不进入本队当前营造区。
5. 准备阶段购买武器，倒计时后近战。全队两人阵亡才出局，最后仍有存活队员的队伍得 1 分。
6. 玩家死亡后优先观战 AI 队友；本队出局后其他 AI 继续战斗。回合结束发放收入、更新比分并进入下一回合。
7. 快速模式仅开局营造；长局模式在领先队首次达到 5 分后、下一回合开始前完整重建一次，保留比分、资金及按存活规则保留的装备。
8. 任一队达到目标分数后显示整场结果，可原模式重开或返回菜单。

## 战斗与经济默认值

- 生命 100；无友军伤害；死亡后本回合不复活。
- 初始每人 `$900`，资金上限 `$6000`。
- 每回合每人基础收入 `$1100`，所在队获胜额外 `$500`，每次个人击败额外 `$200`。
- 回合存活者保留武器；阵亡者下回合恢复免费短刃。重新购买会直接替换手中武器，不退款。
- 商店只在准备阶段开放；AI 使用独立资金与同一价格表。
- 五种实际装备：免费短刃、疾速短刀、均衡打刀、重斧、长柄薙刀。距离、伤害、挥动阶段、攻击扇形、收招和破架能力均不同。
- 攻击由起手、有效帧、收招组成；判定检查距离、方向、攻击弧度和实体遮挡，同次挥击不会重复伤害同一目标。
- 正面 120° 格挡可免伤但消耗架势；架势不足会被破架并承受部分伤害。重斧破架能力最强。
- 每回合 75 秒；35 秒进入“终局揭示”，公开敌人位置并让 AI 主动追击；超时仍有多队存活则平局且不加分。

## 地图与美术

主题为“**四象浮世演武场**”：纸张色地面、墨色描边、四色队伍、日式门架、灯笼和程序化山景。所有模型、地面纹理、标识与音效均在本地程序化生成，无需下载外部模型或音频。

地图为连续 40×40 米场地，四块 15×15 米区域由 6 米宽公共道路连接。每区拥有等预算、对称面积和双人出生环。

### 建造安全规则

- 只能在本队区域内编辑，放置与删除距离不超过 7.5 米。
- 真实 OBB 碰撞检查阻止构件重叠、越界、覆盖角色和出生点。
- 每区固定的浅色十字通道不可占用，直接连接公共道路；每次放置后还会重新栅格化碰撞并做出生点到中央区域的路径检查。
- 所有构件只在地面放置，不可叠放；旋转与碰撞同步，AI 导航在每次增删后更新。

## 技术结构

- `src/blade/game.js`：比赛状态机、输入、建造、商店、经济、战斗与 AI。
- `src/blade/world.js`：Three.js 场景、Toon 材质、角色/武器/构件模型、动画与特效。
- `src/blade/navigation.js`：圆形角色碰撞、OBB 检测、视线遮挡、动态网格 A* 导航。
- `src/blade/rules.js`：随机换区、收入、回合判定与中场规则等纯函数。
- `src/blade/config.js`：平衡参数、区域、武器、构件与 AI 布局模板。
- `src/blade/audio.js`：Web Audio 合成挥击、命中、格挡、击败、购买、营造、脚步与阶段提示。

## 测试

```bash
npm test
```

测试覆盖无固定点换区、同时灭绝/平局、经济、中场只触发一次、目标分数边界、近战遮挡、旋转构件重叠与绕墙导航。

保持开发服务器运行，可再执行真实 Chrome 浏览器验收（可用 `CHROME_PATH` 指定 Chromium 可执行文件，用 `GAME_URL` 指定地址）：

```bash
npm run test:browser
```

浏览器验收会检查初始朝向、八人与建造、换区、商店、近战单次命中/距离/方向/遮挡/友军免疫/格挡、同时阵亡、超时平局、AI 绕过低墙与揭示后的高墙、中场鼠标控制门及外墙观战机位，并自动完整模拟快速 5 分和长局 10 分比赛。长局检查中场仅一次、旧构件清除及新布局通路。截图与报告输出到 `artifacts/`。

## 范围与已知限制

- 当前为单人对本地 AI，不包含联网、账号、拾取背包、复杂物理破坏或地形编辑。
- AI 使用视线/记忆、A*、基本跟进、侧移与格挡；不是复杂战术机器人。极端多人挤在狭窄转角时可能短暂停顿，但会重寻路，35 秒揭示与 75 秒超时用于避免死局。
- 场景以同一平层竞技空间为主；无跳跃和垂直平台，优先保证八人近战与动态建筑导航稳定。
- 音效为轻量合成音，未配置写实采样或持续背景音乐。
