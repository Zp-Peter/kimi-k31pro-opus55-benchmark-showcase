# Kimi K3.1 宣传短片 · 分镜脚本

- **片长** 64 秒 ｜ **规格** 1920×1080 · 30fps · H.264 + AAC 立体声（48 kHz）
- **节奏** 120 BPM（1 拍 = 0.5s，1 小节 = 2s），剪辑点、转场、文字砸入都卡在拍点上；16 秒主歌落拍、56 秒终极重击
- **视觉基调** 深空黑 + 月光白 + 电光蓝（#2E7CFF / #4FD1FF）；"Moonshot（登月）"贯穿全片：开场月面黎明 → 结尾回到新月与一点光
- **字体** 中文 PingFang SC（300–600），英文 Inter（300–900），代码 / HUD JetBrains Mono
- **全片通用后期** HDR 渲染 → 子帧积分真实运动模糊（每帧 8–32 个子帧，180° 快门）→ 多级 Bloom → 变形宽银幕光晕（蓝色横向光条）→ 镜头色散与桶形畸变 → ACES 色调映射 + 调色 → 暗角 + 胶片颗粒 + 遮幅
- **品牌说明** 片尾的月相徽记与 "Kimi K3.1" 字标为本片自行设计（Inter 字体排版），不是 Kimi / Moonshot AI 官方标志
- **光敏安全** 按 ITU-R BT.1702 / Ofcom 闪烁准则逐像素自检：任意 1 秒内闪烁超过 3 次的区域最多占屏幕约 6%（上限 25%）；S10b 蒙太奇的闪白隔拍减弱
