# 雷尼斯黑沙滩 · Reynisfjara

用 three.js（r170）程序化生成的冰岛南岸黑沙滩：雷尼斯山（Reynisfjall）崖壁、Garðar 六棱玄武岩柱群、
雷尼斯海蚀柱（Reynisdrangar），以及从北大西洋一路翻滚而来的长周期涌浪。所有几何与纹理都在浏览器里实时生成，
没有任何贴图或模型文件。

## 运行

```bash
python3 serve.py
```

然后打开 <http://localhost:8642/>（端口可作为参数传入：`python3 serve.py 9000`）。
需要支持 WebGL2 的桌面浏览器；three.js 从 jsDelivr CDN 加载，首次打开需联网。

## 操作

| 操作 | 作用 |
| --- | --- |
| 左键拖动 / 右键拖动 / 滚轮 | 旋转 / 平移 / 缩放 |
| `1`–`5` | 机位：海滩、玄武岩柱、海蚀柱、浪花、航拍 |
| `M` | 切换天气：阴天 → 黄金时刻 → 风暴 |
| `H` | 隐藏界面（纯净画面） |
| 空格 | 暂停 / 继续 |
| 右上「参数」 | 太阳、海况、雾与云、画面（时间流速、反射、泛光、分辨率等） |
| 右下「声音」 | 程序化海浪与风声（按浪的节奏合成） |

## 场景里有什么

- **黑沙滩**：带湿润分区的物理材质。冲刷水膜会反射崖壁和海蚀柱，干沙上有风成沙纹，还有闪烁的玄武岩砂粒和卵石接触阴影。
- **海浪**：外海是 8 组 Gerstner 涌浪。近岸碎浪的浪高与破碎位置逐浪不同、沿岸起伏变化；破碎前浪面陡峭发绿，碎后成为白色涌潮，在身后留下逐渐消散的泡沫花边，最后冲上沙滩又退回。约每十几道浪会来一道格外大的「疯狗浪」。
- **崖壁与岩石**：雷尼斯山崖壁有熔岩层理、扶壁和冲沟，山顶覆盖苔草。玄武岩柱群用 Voronoi 柱体堆出阶梯和洞穴，柱面有节理。海蚀柱带有锯齿状的峰脊。坡脚散落着断柱、巨石和数千颗卵石。
- **大气**：分层云盖的天空，带高度衰减并随太阳方向染色的雾，环境光由天空实时烘焙。
- **其他**：成群绕崖飞行的暴雪鹱（拍翼、倾斜转弯），海面平面反射，以及泛光、AgX 色调映射、暗角和胶片颗粒。

## 目录

```
index.html          界面与 importmap
serve.py            本地静态服务器（禁用缓存）
src/main.js         场景装配、渲染循环、机位与天气
src/config.js       布局、机位、三种天气的全部参数
src/world/          沙滩、海洋、崖壁、玄武岩柱、海蚀柱、卵石、海鸟、天空、程序纹理
src/glsl/           噪声、碎浪与冲刷模型（GLSL + JS 镜像）、高度雾
src/fx/             平面反射、后期
src/audio.js        WebAudio 程序化海浪声
```

画面卡顿时，可在「参数 → 画面」里降低渲染分辨率或关闭平面反射。
