# 换庭斩 · SWAP BLADE

3D 第一人称、三渲二（卡通描边）风格的四队近战刀战 Demo。
4 队 × 2 人：你 + 1 名 AI 队友，对抗 3 支 AI 队伍。每队先在自己负责的庭院摆放掩体，建完后**随机换区**：每队都在别队建的庭院出生（每回合重抽）。回合内阵亡不复活，最后还有人存活的队伍得 1 分。

技术栈：TypeScript + three.js + Vite。没有外部美术或音频资源：模型、贴图、音效和 BGM 都由代码生成。

## 一局的流程

1. **建造**（150 秒，中场重建为 120 秒）。
   - 跟着黄色光柱和屏幕边缘的箭头，走到本队负责的庭院。
   - 每队都有 20 点相同预算，只能在本队区域、准星 8.5 m 内摆放。
   - AI 队伍按模板加随机变化建造。AI 队友只会补全剩余预算，不会删除或改动你放的构件。
   - 如果你一个都没放就到时间了，队友会自动替你布置。
2. **锁定检查**（2.8 秒）：校验每个出生点都有通往外部的通路；如果有构件封死通路，会自动移除并提示。
3. **随机换区**（5.5 秒）：俯瞰全图，展示各区的建造者和本回合出生队伍。
   - 四队与四个区一一对应，且不在自己建的区出生（错位排列）。
   - 只交换出生位置，队伍、颜色、分数、金钱、装备都不变。
   - 之后每回合都会重新抽取。
4. **准备 / 购买**（建造后第一次 20 秒，之后 15 秒）。第一次会自动打开军械架；出生台结界在开战前不会解除。玩家点“准备就绪”后，剩余时间缩短为 3 秒。
5. **战斗**（100 秒）：友伤关闭。阵亡后先看 1.8 秒的阵亡镜头（看向击杀者），然后进入第三人称观战，优先观战队友。
6. **回合结算**（5.5 秒）：胜负原因、四队比分、你的收入明细、装备保留或恢复说明。然后进入下一回合：换区 → 购买 → 战斗。

| 模式 | 胜利条件 | 建造 |
| --- | --- | --- |
| 快速模式 | 先到 5 分 | 只在开局建造一次 |
| 长局模式 | 先到 10 分 | 开局建造一次 + 中场重建一次 |

结束后显示整场结算：冠军、比分、每个角色的击杀、阵亡、伤害、金钱。可选“再来一局”（同一模式）或返回主菜单。暂停菜单里也可以重新开始本局。

## 地图主题：四季庭院

紧凑的正方形和风庭院（可走区域约 58 m × 58 m），四重旋转对称，所以四个区的地形完全等价。

```
 A 松庭（西北） │ 北廊 │ B 竹庭（东北）
 ───────────────┼──────┼───────────────
       西廊     │ 中央 │     东廊
                │ 高台 │
 ───────────────┼──────┼───────────────
 D 樱庭（西南） │ 南廊 │ C 枫庭（东南）
```

- **四个庭院（建造区）**：各 20 m × 20 m。出生台在外角，旁边有武器架。每个庭院有 2 个侧门和 1 个角门，从出生点都有宽阔路线通往外部。
- **公共空间**：庭院之间的四条廊道（亭子、石灯、竹丛、水钵），以及中央广场和带太鼓的高台（4 个方向都有楼梯）。结界最终会收缩到这里。
- **辨识**：每个区有字母 + 庭名 + 植物主题（松 / 竹 / 枫 / 樱）。
  - 建造阶段会显示本队区域的边界、保留区斜线和区域字母，并用黄色光柱和屏幕箭头指向本队区域；光柱在你走近后自动变淡。
  - 区域旗帜颜色 = 建造者。换区和准备阶段，出生台结界颜色 = 本回合在此出生的队伍。
- **建造限制**：不可叠放；出生台和三个门口是保留区；不能卡住角色；不能封死出生点通往外部的最后一条通路。这几条在放置时实时校验，锁定时再检查一次。

## 战斗方案

**一次挥砍的结构**：每次攻击都分为 蓄力 → 判定 → 收招 三段，第一人称武器动作与判定时间完全同步。

- 只有判定帧能命中，并且每次挥砍对同一目标只结算一次。
- 命中需要同时满足四个条件：
  - **距离**：在武器攻击距离内
  - **方向**：在攻击扇形内
  - **高度差**：不超过 1.3 m
  - **遮挡**：双方胸口连线不能穿过墙体或构件（矮墙挡刀但不挡视线）
- 同一帧内的命中先收集再统一结算，因此最后两队同时倒下会判为平局。

| 武器 | 价格 | 招式（伤害 / 距离 / 蓄力） | 特点 |
| --- | --- | --- | --- |
| 短刀 | 免费 | 横斩 18 → 横斩 18 → 突刺 30；1.95–2.15 m；0.10–0.16 s | 三连击，移速 +10%，弹反窗口最宽；距离最短。击杀奖励 $500 |
| 打刀 | $600 | 横斩 34 → 横斩 38；2.5 m；0.18–0.2 s | 攻防均衡，100° 宽横斩，格挡稳定。击杀奖励 $350 |
| 薙刀 | $1000 | 突刺 40（3.45 m）→ 横扫 30（150°）；0.3–0.36 s | 距离最远；贴身时只能用柄打，伤害减半；收招慢。击杀奖励 $300 |
| 鬼斧 | $1500 | 下劈 75；2.6 m；蓄力 0.58 s | 霸体蓄力，劈中格挡必定破防；落空破绽大，移速 -12%。击杀奖励 $200 |
| 胴甲 | $400 | +40 护甲 | 优先抵消伤害；回合存活可保留剩余护甲 |

**防守**

- **格挡**：防住正面约 156° 内的攻击，只受少量削血；同时消耗架势值（100，停止受击 0.9 秒后以每秒 40 恢复）。架势被打空或被鬼斧劈中，就会**破防**：硬直 0.7 秒，并承受一半伤害。
- **弹反**：在刚举起格挡的窗口内挡住攻击（0.15–0.2 秒，按武器不同），攻击者硬直 0.85 秒（重击 1.15 秒）。连续按格挡不会触发弹反，必须间隔 0.35 秒以上重新举起。
- **闪避**：0.24 秒位移，其中 0.18 秒无敌，冷却 1 秒。
- **背刺**：从背后（偏离目标朝向 115° 以上）命中，伤害 ×1.25。

**反馈**

- 命中：命中标记、伤害数字（背刺 / 格挡 / 弹反 / 破防 / 闪避都有文字）、顿帧、击退、镜头冲击与晃动、受击红边与方向指示。
- 击杀：“斩！”横幅、击杀提示和击杀音效。
- 音效：格挡与弹反各有专属火花和音效。
- AI 攻击可读：蓄力时武器闪光并有提示音，然后才挥出。
- 第一人称武器单独渲染，贴墙也不会穿模；视角平稳，阵亡和观战镜头带碰撞检测。

**AI**

- 会购买装备、用 A* 绕开构件寻路、靠视线 + 听觉发现敌人、交战、格挡 / 弹反 / 闪避，并带反应时间；卡住时会自动重新寻路。
- 每个 AI 有性格（斗士 / 剑客 / 枪手 / 刺客 / 稳健），决定武器偏好、攻击性和护甲习惯。难度分简单 / 普通 / 困难，影响反应、格挡与弹反概率、转身速度。
- 6 个敌方 AI 各自按距离、可见性、残血和仇恨选目标，对玩家没有额外加权。已被两名以上其他队伍 AI 盯上的目标会降低优先级，所以 AI 队伍之间也会互相厮杀，不会集体只追玩家。
  - 模拟统计：玩家存活时，大多数时间有 0–2 个敌方 AI 以玩家为目标（2 个通常是同一队），三支敌队同时围攻玩家极少出现。
- AI 队友跟随在你身侧后方，你交战时会赶来支援。

## 经济（CSGO / Valorant 式）

| 项目 | 数值 |
| --- | --- |
| 初始资金 | $800 |
| 每回合基础收入 | 所有人 +$500（平局也发） |
| 胜队额外 | 每人 +$500 |
| 连续未胜补偿 | 每回合 +$150，最多 +$450 |
| 击杀奖励 | 按击杀时所持武器：短刀 $500 / 打刀 $350 / 薙刀 $300 / 鬼斧 $200（即时到账） |
| 资金上限 | $5000 |
| 护甲 | $400 = 40 点 |

- 军械架只在准备阶段开放。界面显示：当前资金、价格、特性、当前装备、队友装备与资金，以及每次购买的结果。资金不足的物品会提示还差多少。
- 不会扣成负数，也不会重复扣款：重复购买已装备的武器不收费；本阶段买的武器可以原价退回或替换。
- 买下即真正装备（第一人称和角色模型立即换刀）。
- **装备规则**：存活者保留武器与剩余护甲；阵亡者下回合恢复为免费短刀，失去护甲。
- AI 与玩家价格完全相同，走同一个购买接口。

## 中场重建触发（长局模式）

- 领先队**首次达到 5 分**的那个回合结算后、下一回合开始前触发，整场只触发一次。快速模式没有中场重建。
- **保留**：分数、金钱、按装备规则保留的武器和护甲。
- **清空**：全部旧构件。所有 8 人（包括本回合阵亡者）回到中央集合，期间不能战斗。
- 重新分配建造区：每队都分到与上次不同的区，并获得相同的新预算 20 点，重建时间 120 秒。建完后按新的建造关系重新随机换区，继续正常回合。
- 不额外插入战斗回合，也不重复发放回合奖励。屏幕上会弹出“中场重建”说明面板。

## 超时与防躲藏规则（界面里有横幅、顶部提示条和规则页说明）

- 每回合 100 秒。
- **剩 45 秒：全员显形**。所有敌人的头顶标记穿墙可见，AI 同样获得全部位置。
- **剩 30 秒：结界收缩**。结界从地图边缘（半径 44 m）向中央高台（半径 4 m）收缩，圈外每秒 -9 HP（护甲先抵消）。
- **时间到仍有多队存活**：平局，不加分，所有人照常获得基础收入。
- **最后几队同时阵亡**（同一帧）：平局，规则同上。

## 验证情况

### 已实际运行验证（浏览器内 + 脚本模拟）

- **完整对局（浏览器 UI 流程）**：开始比赛 → 建造（放置、删除退还、撤销、队友补全、准备）→ 锁定 → 换区俯瞰 → 准备阶段 → 战斗 → 阵亡镜头 → 观战队友 → 回合结算 → 后续回合 → 整场结算 → 再来一局 / 返回主菜单 / 暂停菜单重新开始。
- **商店**：购买打刀 $800→$200 并立即装备；重复购买不扣款；资金不足被拒绝（提示还差多少）；换回短刀原价退回 $600；护甲购买与“已满”提示。
- **近战**：
  - 2.6 m 外用短刀挥空，1.5 m 内三连击依次扣 18 / 18 / 30。
  - 格挡打刀只受 4 点削血、架势 100→65。
  - 卡时机格挡触发弹反：对手硬直 0.85 秒，出现“弹反！”。
- **AI**：会在准备阶段购买（同价），会主动攻击玩家和队友。玩家阵亡后，AI 之间继续交战直到分出胜负。
- **长局中场重建（UI 流程）**：领先队首次到 5 分后触发一次，说明面板正常显示。分数与金钱保留，构件清空，4 队建造区全部与上次不同，8 人全部存活且不可战斗。
- **防躲藏**：冻结所有 AI 后，剩 45 秒触发全员显形，敌人标记穿墙可见；剩 30 秒结界收缩并持续扣血。
- **超时平局**：把 8 人都放在终圈内不战斗，时间到判平局，不加分，每人只得基础收入 $500。
- **菜单不误操作**：商店打开时鼠标移动和点击不改变视角、不出刀；关闭后视角控制恢复。
- **批量模拟**（`runMatch`，含生产构建）：
  - 规模：快速模式 20 余局、长局 4 局，全部正常结束。
  - 换区：每回合都是合法的错位排列，没有任何队伍在自建区出生。
  - 中场重建：长局都只重建一次。
  - 金钱：无负数，不超过上限。
- **构建**：`npm run build`、`npm run build:single` 均成功。单文件版通过本地静态服务器加载，控制台无报错，并跑完一整局模拟。
- **性能参考**（Apple M1 Pro，1280×800、像素比 1.5）：一帧约 2–3 ms（游戏逻辑 + 渲染，含 GPU 同步），约 1000 次 draw call。

### 限制与未验证项

- **鼠标锁定**：测试用的内嵌浏览器不允许 Pointer Lock，鼠标视角是在兼容模式下验证的。正常浏览器里的锁定流程用的是标准 API，但没有在真实浏览器窗口中手动试玩。
- **声音**：全部为 WebAudio 合成。只确认了运行无报错，没有实际试听音量和混音效果。
- **双击打开**：单文件版是通过 http 加载验证的，没有直接测试 `file://` 双击打开（内联脚本通常可以正常运行）。
- **美术**：程序化低多边形加卡通着色，角色动作是关键帧插值，没有骨骼动画或手工模型。
- **AI 行为**：有性格和难度差异，但战术较简单（不会主动包抄或配合埋伏）。
- **平局频率**：AI 对战中平局很少出现，模拟中回合基本都在超时前分出胜负。平局规则用专门的场景测过。
- **局时**：长局（先到 10 分）在模拟中约 27–31 回合，真人一局可能要 25 分钟以上。
- **平台**：只支持键鼠，不支持手柄、触屏和移动端；没有联机。
- **性能**：没有在低端设备上测试。

## 调试接口（不影响正常计分）

在浏览器控制台中使用 `__game`：

```js
__game.runMatch('quick', 42)   // 无头 + 自动驾驶打完一整局，返回比分、换区记录、建造记录、金钱检查等
__game.runMatch('long', 7)     // 长局（含中场重建）
__game.autopilot(true)         // 让 AI 接管玩家角色（可观看完整流程）
__game.timeScale(4)            // 加速
__game.skip()                  // 跳过当前阶段倒计时
__game.state()                 // 当前阶段、比分、建造区 / 出生区、存活、金钱、武器
```

## 项目结构

```
index.html            页面骨架：HUD、菜单、商店、结算等 DOM
src/main.ts           入口与调试接口
src/game.ts           总控：渲染器、主循环（固定子步）、事件分发、镜头与后处理参数
src/config.ts         队伍、区域、模式、时间、经济、难度等全部可调参数
src/game/             玩法：match 流程与换区 / character 状态机 / combat 判定 / weapons 武器与招式关键帧
                      build 建造与校验 / shop 商店 / ai 行为 / player 输入、建造交互、观战与镜头
src/world/            地图布局、碰撞（AABB + 圆柱）、导航网格与 A*、构件定义、地图网格生成
src/render/           卡通材质、几何合并、天空、后处理（法线 / 深度描边 + 合成 + FXAA）
src/view/             角色模型、第一人称武器、刀光与粒子特效、武器模型
src/ui/               HUD 与各类菜单 / 面板
src/audio/audio.ts    合成音效与 BGM
```
